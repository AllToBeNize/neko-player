# Windows

Windows 播放器第一版，采用 Tauri 2 + Vue 3 + TypeScript + Rust。

在此目录执行 `npm install`，然后执行 `npm run desktop` 启动桌面窗口。需要 Node.js、Rust MSVC、Visual Studio C++ Build Tools 和 WebView2。启动脚本会自动补充用户目录中的 Cargo 路径。

已实现：B 站扫码登录入口、搜索视频、解析首个分 P 的 AAC 音轨、播放/暂停/跳转/音量/循环/随机、播放队列、本地歌单、收藏、最近播放、歌曲清单导入及人工关联音源。SQLite 保存歌单，Windows 凭据管理器保存登录 Cookie。

支持直接搜索 BV 号或含 BV 号的视频链接，返回对应视频并播放首个分 P 音轨。听歌识曲支持麦克风录制最多 12 秒，或读取小于 20 MB 音频文件的前 12 秒，转为单声道 WAV 后提交 AudD；识别结果可继续搜索 B 站。此功能需要在界面配置用户自己的 AudD API Token，保存在 Windows 凭据管理器，额度和费用由服务商决定。未配置时不会采集或上传音频，不支持哼唱。音频只在内存处理，关闭录音界面会停止采集；已发出的识别请求不能从服务端撤回。

识曲接口按 [AudD 官方文档](https://docs.audd.io/)实现；当前已验证入口、未配置状态和输入校验，尚无实际 Token，完整识别结果待配置后验收。

本地文件通过文件选择器临时播放，不保存文件授权或 blob URL，下次启动需重新选择。当前播放使用 WebView2 音频及本地流代理，尚未接入规划中的独立原生音频引擎、托盘和系统媒体键。当前为开发启动方式，尚未生成安装包。

酷狗导入支持官方短链接及包含 global_collection_id 的分享歌单，保留分享签名相关参数，HTTP 跳转升级为 HTTPS 后访问。每页读取 100 首，核对总数、版本和重复分页，完整成功后才保存。保留歌名、歌手、原平台 hash、时长及封面，之后可逐曲搜索并关联 B 站音源。仍支持每行 `歌手 - 歌名` 的歌曲清单导入；其他酷狗分享格式不保证兼容。

B 站登录支持两种入口：默认的「密码 / 短信登录」会打开独立的官方网页登录窗口，按官方页面选择密码或短信登录并完成安全验证，登录成功后自动保存凭据、关闭登录窗口并更新播放器账号；也可切换「扫码登录」。应用不读取密码或短信验证码，在打开官方登录窗口后自动检测本机网页登录 Cookie、验证账号并写入 Windows 凭据管理器。登录窗口使用独立目录和隐私模式，无应用 IPC 授权，关闭后不保留网页登录会话；不会同步系统浏览器账号。已验证窗口创建、重复打开复用、未登录拦截、取消关闭及扫码入口，实际密码/短信登录由用户完成后验收。

详细设计见 [技术说明](../docs/architecture.md)。验证用文件位于项目外并在验证后删除，不纳入源码或提交。

导入歌单后自动启动 B 站音源匹配：按「歌手 + 歌名」搜索，歌手证据占 55%、歌名相似度占 35%、时长占 10%。对翻唱、现场、伴奏、变速和合集等不一致版本降权，时长差距过大也降权。按用户选择的策略，存在候选时默认关联综合得分最高的一项；实际播放时再解析音轨与验证访问权限。临时播放链接不写入歌单。

每首保存至多八个候选及歌手、歌名、时长分项评分和解释。右键「更换歌源」可试听、重新搜索并更换，已有手动选择优先保留。人工选择的映射不会被自动覆盖。请求串行且间隔至少 1.6 秒；连续三次请求失败会暂停。后台进度支持暂停，已有关联结果持久化；旧歌单点击「自动匹配音源」处理未匹配或失败条目，旧版已有候选会重新评分并默认选择第一项，失败或无候选条目可重试。当前为规则评分算法，不代表已验证整份歌单的匹配准确率。

官方网页登录每两秒顺序检测一次，检测到有效会话并保存系统凭据后自动关闭窗口；取消或切换扫码时停止检测。应用前端重新加载时，会尝试接续仍打开的官方登录窗口。账号验证失败时保留窗口并重试，不把失败状态当作登录成功。
已登录后会自动补匹配已有导入歌单中尚未处理的歌曲，打开歌单也会检查是否需要启动。已有关联的条目不重复搜索；同一会话内用户暂停的歌单不会因重新打开而自动重启，需点击自动匹配按钮继续。界面区分尚未匹配、排队、当前搜索、待确认及失败状态。

2026-11-08 歌曲详情、歌词、主题与音量平衡：

- 播放歌曲后点击左下角封面，展开歌曲详情与歌词页，底部播放器继续可用。支持播放控制、收藏与换源。
- 歌词优先以原平台 hash、歌名、歌手、原时长查询酷狗，候选核对名称和时长；未匹配时尝试 LRCLIB。成功歌词单独缓存在 SQLite。LRC 按播放时钟逐行高亮和滚动，点击歌词跳转；支持手动重新匹配、导入 LRC/TXT、保存选择及 ±30 秒时间偏移。纯文本歌词明确标注无时间轴，不伪造同步。音源与歌词版本不同可能需要偏移调整或更换歌词。
- 顶栏调色盘可选择翡翠绿、海盐蓝、鸢尾紫、朱砂红，强调色统一用于按钮、播放模式、选中项及当前歌词。四套主强调色与白色按钮文字的对比度均不低于 4.5:1。主题保存在本地偏好中。
- 底部波形按钮和详情页开关控制音量平衡，默认开启，状态会保存。Web Audio 分析原始信号的平滑 RMS，约 1.25 秒有效采样后缓慢调整增益，目标约 -18 dBFS RMS；增益限制约 -12 至 +10 dB，低于约 -50 dBFS 的信号不触发放大，并以动态压缩降低过载风险。它是实时电平平衡，不是 EBU R128/LUFS 离线整曲标准化，也不保证所有录音听感完全一致。
- 用户音量由处理链末端独立的主增益控制，分析点位于该增益之前，避免音量平衡抵消用户音量。关闭音量平衡时自动增益回到 1、压缩比回到 1，保留用户音量。
- 音频本地代理对已注册的随机媒体地址返回 CORS 头，供 Web Audio 读取信号；不支持任意 URL 代理。
